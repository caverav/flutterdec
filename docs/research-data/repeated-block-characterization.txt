Repeated-block characterization
================================

Scope: current structured and DFS pseudocode emission.

1. A structured walk may render an already emitted region again only when
   is_repeatable_region accepts it.
2. The accepted region contains at most 16 blocks and 96 LLIR instructions.
3. Reaching the innermost active loop header ends the repeated region and emits
   continue; the loop header itself is not duplicated.
4. Reaching another loop header declines structured emission.
5. repeated_blocks increments once for each structured block copy. DFS fallback
   duplication is intentionally outside this counter.
6. A declined structured attempt restores the repeated_blocks counter before
   direct DFS emission.
